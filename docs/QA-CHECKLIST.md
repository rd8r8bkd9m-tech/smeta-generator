# QA Checklist - SMETA PRO

## Перед релизом

### Критические проверки (P0)

- [ ] API запускается без ошибок
- [ ] Web приложение загружается
- [ ] Health check возвращает 200 OK
- [ ] Авторизация работает (логин/регистрация)
- [ ] Калькулятор рассчитывает сметы
- [ ] AI генерация работает (demo mode или с ключом)
- [ ] Данные сохраняются в БД

### Функциональные проверки (P1)

#### Авторизация
- [ ] Регистрация нового пользователя
- [ ] Вход существующего пользователя
- [ ] Выход из системы
- [ ] Защита роутов от неавторизованных

#### Калькулятор
- [ ] Добавление позиций в смету
- [ ] Изменение количества
- [ ] Удаление позиций
- [ ] Расчет итогов (subtotal, overhead, profit, VAT)
- [ ] Применение шаблонов

#### AI генерация
- [ ] Генерация по текстовому описанию
- [ ] Корректные позиции для "штукатурка стен 109 м2"
- [ ] Расчет материалов и работ
- [ ] Demo mode работает без API ключа

#### Проекты
- [ ] Создание проекта
- [ ] Редактирование проекта
- [ ] Удаление проекта
- [ ] Список проектов

#### Клиенты
- [ ] Создание клиента
- [ ] Редактирование клиента
- [ ] Удаление клиента
- [ ] Список клиентов

#### Шаблоны
- [ ] Просмотр списка шаблонов
- [ ] Применение шаблона к смете
- [ ] Фильтрация шаблонов

### UI/UX проверки (P2)

- [ ] Адаптивность на мобильных устройствах
- [ ] Темная тема работает
- [ ] Анимации плавные
- [ ] Loading состояния отображаются
- [ ] Ошибки показываются пользователю
- [ ] Валидация форм работает

### Безопасность

- [ ] JWT токены валидируются
- [ ] Rate limiting работает
- [ ] CORS настроен правильно
- [ ] Пароли хешируются
- [ ] SQL инъекции невозможны (Prisma)
- [ ] XSS защита (helmet)

### Производительность

- [ ] Страницы загружаются < 3 сек
- [ ] API отвечает < 500ms
- [ ] Нет утечек памяти
- [ ] Кэширование работает

## Автоматические тесты

```bash
# Запуск всех тестов
pnpm test

# Ожидаемый результат:
# ✓ 79 tests passed
# ✓ 5 test files
```

## Smoke тест (ручной)

1. Открыть http://localhost:3002
2. Зарегистрировать нового пользователя
3. Войти в систему
4. Перейти в калькулятор
5. Ввести "штукатурка стен 109 м2"
6. Нажать "Сгенерировать"
7. Проверить что появились позиции
8. Изменить количество одной позиции
9. Удалить одну позицию
10. Проверить итоговую сумму

## Команды для проверки

```bash
# Health check
curl http://localhost:4000/api/health

# Тест AI генерации
curl -X POST http://localhost:4000/api/ai/generate \
  -H "Content-Type: application/json" \
  -d '{"description":"штукатурка стен 109 м2","area":109}'

# Тест калькулятора
curl -X POST http://localhost:4000/api/calculator/calculate \
  -H "Content-Type: application/json" \
  -d '{"items":[{"id":"1","name":"Штукатурка","unit":"м²","quantity":109,"price":450}]}'

# Тест шаблонов
curl http://localhost:4000/api/calculator/templates
```
