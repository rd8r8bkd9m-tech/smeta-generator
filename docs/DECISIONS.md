# Status App — Принятые решения

## 🏗 Архитектура приложения

### Структура проекта
**Решение**: Создать отдельное приложение `apps/mobile-web` в монолитном workspace вместо использования существующего `apps/web`.

**Причина**: Чистое разделение между desktop/web приложением и мобильной PWA. Позволяет иметь разные настройки сборки, зависимости и конфигурации.

### Маршрутизация
**Решение**: Использовать React Router v6 с плоской структурой маршрутов.

**Причина**: Простота, читаемость и соответствие требованиям (12 экранов с четкими путями).

## 🎨 Дизайн-система

### Цветовая палитра
**Решение**: Dark-first подход с холодным голубым акцентом (#3b82f6).

**Причина**: Современный тренд, премиальное ощущение, хорошая контрастность для мобильных устройств.

### Стеклянные эффекты (Glass morphism)
**Решение**: `backdrop-blur-xl` с `opacity: 0.08-0.16` и тонкими бордерами.

**Причина**: Создает ощущение глубины и премиальности без перегруженности.

### Типографика
**Решение**: Inter как основной шрифт с оптимизированными размерами для мобильных.

**Причина**: Читаемость на мобильных, современный вид, хорошая поддержка кириллицы.

## 🧩 Компоненты

### DeviceFrame
**Решение**: Реализовать как компонент с фиксированными размерами iPhone 15 Pro (393×852).

**Причина**: Точное соответствие требованиям (1:1 экраны), возможность переиспользования для тестирования.

### StoryRing
**Решение**: SVG с градиентным кольцом для непросмотренных статусов + пульсирующая анимация.

**Причина**: Визуально привлекательно, показывает прогресс, соответствует Instagram/Snapchat паттернам.

### AppShell
**Решение**: Единый layout с градиентным фоном, safe areas и bottom navigation.

**Причина**: Консистентность навигации, правильная работа с iOS/Android safe areas.

## 🎭 Анимации

### Framer Motion
**Решение**: Использовать для всех анимаций с `duration: 0.2-0.3s` и `ease: 'easeOut'`.

**Причина**: Плавность, производительность, простота контроля над последовательностями.

### Stagger анимации
**Решение**: Применять для списков элементов с задержкой 0.05-0.1s между элементами.

**Причина**: Создает ощущение "оживания" интерфейса, премиальное ощущение.

## 📊 Данные

### Моковые данные
**Решение**: Создать реалистичные данные в `src/mock/data.ts` с типами TypeScript.

**Причина**: Позволяет сразу видеть приложение в "продакшн" состоянии, легко заменить на API позже.

### Структура данных
**Решение**: Типизированные интерфейсы для User, Story, Reaction, InboxItem.

**Причина**: Type safety, возможность расширения, соответствие REST API паттернам.

## 🔧 Технические решения

### PWA
**Решение**: Настроить через vite-plugin-pwa с минимальным manifest и service worker.

**Причина**: Требование мобильной PWA, offline возможности, установка на домашний экран.

### Tailwind CSS
**Решение**: Расширить конфигурацию кастомными токенами вместо CSS variables.

**Причина**: Лучшая производительность, типизация, интеграция с существующей дизайн-системой.

### TypeScript
**Решение**: Строгие настройки с `noUnusedLocals` и `noUnusedParameters`.

**Причина**: Качество кода, предотвращение ошибок, лучшая поддержка в IDE.

## 📱 Мобильная оптимизация

### Viewport
**Решение**: `viewport-fit=cover` и CSS safe-area-inset переменные.

**Причина**: Правильная работа с вырезами и закруглениями на современных устройствах.

### Touch targets
**Решение**: Минимальный размер 44×44px для интерактивных элементов.

**Причина**: Соответствие iOS HIG и Android Material Design гайдлайнам.

### Performance
**Решение**: Lazy loading компонентов, оптимизированные изображения, minimal bundle.

**Причина**: Быстрая загрузка на мобильных сетях, хорошие Core Web Vitals.

## 🚀 Развертывание

### Vite
**Решение**: Использовать Vite с React plugin и PWA plugin.

**Причина**: Быстрая разработка, оптимизированная сборка, отличная поддержка PWA.

### Workspace
**Решение**: Интегрировать в существующий pnpm workspace с общими пакетами.

**Причина**: Переиспользование кода, единая система сборки, простое управление зависимостями.

## 🎯 UX/UI решения

### Stories паттерн
**Решение**: Следовать Snapchat/Instagram Stories с кольцами, прогрессом и жестами.

**Причина**: Привычный паттерн для пользователей, эффективное потребление контента.

### Bottom navigation
**Решение**: 5 табов с центральной кнопкой создания (как Instagram).

**Причина**: Стандартный паттерн мобильных приложений, удобный доступ к основным функциям.

### Empty states
**Решение**: Дружелюбные пустые состояния с иконками и подсказками.

**Причина**: Лучший пользовательский опыт, guidance для новых пользователей.
